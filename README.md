# 🎟️ Eventify — Campus Event Management Platform

A modern, full-stack web application designed to streamline event organization, ticketing, and student engagement across university campuses.

[![Live Demo](https://img.shields.io/badge/Live-Demo-brightgreen?style=for-the-badge&logo=vercel)](https://eventify-project-mu.vercel.app)
[![Backend Status](https://img.shields.io/badge/Backend-Render-46E3B7?style=for-the-badge&logo=render)](https://render.com)
[![Database](https://img.shields.io/badge/Database-Neon%20Postgres-00E599?style=for-the-badge&logo=postgresql)](https://neon.tech)

---

## 🌟 Key Features

- **Multi-Role RBAC System:** Dedicated dashboards and permissions for System Administrators, Club Leaders, and Students.
- **Guest Access:** Public event exploration with real-time attendee stats and details without mandatory login.
- **Full Mobile Responsiveness:** Custom Vanilla CSS styling with a responsive mobile drawer navigation and touch-optimized data views.
- **High Security:** Stateless JWT authentication, Bcrypt password hashing, and role-guarded endpoints via Spring Security.
- **24/7 Availability:** Keep-alive ping integration to eliminate free-tier container sleep cycles.

---

## 🛠️ Tech Stack

- **Frontend:** React, Vanilla CSS3 (Flexbox & Grid), Fetch API.
- **Backend:** Java 17, Spring Boot, Spring Security, Spring Data JPA, Hibernate.
- **Database:** PostgreSQL (Hosted on Neon Cloud).
- **Deployment & Hosting:** Vercel (Frontend), Render (Backend), UptimeRobot (Availability).
